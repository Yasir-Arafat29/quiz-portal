# 🎯 Quiz Portal

A full-stack online quiz management system built with Spring Boot, PostgreSQL, and Vanilla JavaScript.

## 🚀 Features

### 🔐 Authentication
- User Registration & Login
- Role-based access (ADMIN / USER)
- Session management with localStorage

### 📚 Admin Panel
- Category Management (Create, Edit, Delete)
- Quiz Management with auto-generated share codes
- Bulk Question Add (multiple at once)
- Question Edit via Modal
- User Management
- Complete History

### 🎯 User Panel
- Browse available quizzes
- Take quizzes with live timer
- Auto-scoring & instant results
- Personal quiz history
- Share quizzes via WhatsApp / Email
- Join quizzes using shareable codes

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | HTML5, CSS3, Vanilla JavaScript (ES6+) |
| **Backend** | Spring Boot 3.2, Java 21 |
| **Database** | PostgreSQL 18 |
| **ORM** | Hibernate (Spring Data JPA) |
| **Build Tool** | Maven |
| **IDE** | VS Code |
